# Studio code map

Keep this file current: every change that adds, moves, splits or re-purposes a file updates its line.

Read this first to find code; grep only inside the files it points to. Paths are relative to the repository root;
the package is `editor/capsule_studio/` (shortened to `cs/` below).
Line format: `path` - what it owns. **K:** key classes / functions. **M:** manifest keys or schema it edits.
A package that changes a file may append its tag, e.g. `[S5a]`.

## Layering

| Layer | Folder | Rule |
| --- | --- | --- |
| core | `cs/core/` | editing logic, no Qt import anywhere; the engine's compilers stay the one authority (imported via core/engine.py) |
| cli | `cs/cli/` | `capsule-studio ...` over core; no display |
| plugins | `cs/plugins/` | extension host (D-10): loading, registry, purity |
| extensions | `cs/extensions/<area>/<name>/` | built-in plugins: commands.py (CLI), maptools.py (no Qt), panel.py (Qt), extension.py |
| ui | `cs/ui/` | PySide6 shells (windows) and panels (`ui/editors/`); panels edit only through host.run_edit() |
